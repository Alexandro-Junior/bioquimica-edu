📞 SUPORTE
───────────────────────────────────────────────────────────────────────────────

Desktop não funciona?
  → Certifique-se: Python 3.9+, Tkinter instalado
  → python -m tkinter (deve abrir janela teste)

Mobile (Kivy) não funciona?
  → pip install kivy --upgrade
  → Certifique-se: data/ no mesmo dir que main_kivy_completo.py

Android APK não compila?
  → Siga INSTALAR_MOBILE.md
  → Requer: JDK 11+ , SDK Android, Buildozer
  → Alternativa: Kivy Cloud (online, sem setup local)
